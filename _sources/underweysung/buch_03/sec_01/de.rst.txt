Seülen, Vitruvius, Sechs Hobelzierden & Gewundene Kugel-Seüle (Fig. 1–19)
=========================================================================

*Das dryt büchlein / von den Corperlichen dingen.* *(Camerarius 1532: Liber Tertius — De columnis,
pyramide, horologiis ac litterarum figuris.)*

So man aber von dem gantzen bauwerck oder seynen teylen reden will / acht jch es sey keynem
berümbten baumeister oder werckman verborgen wie künstlich vnd meysterlich der alt Römer
:person:`Vitruuius <vitruvius>` in seinen bücheren von der bestendigkeyt / nutzbarkeyt / vnnd
zierden der gebeü geschryben hab / der halb jme auch for anderen zuᵒfolgen / vnd sich seiner ler
zuᵒbrauchen ist. So jch aber ytzo für nym ein seülen oder zwo leren zuᵒmachen / für die jungen
gesellen / sich darynn zuᵒ vben / so bedenck jch der deütschen gemüt / dann gewonlich alle die
etwas newes bauwen wöllen / wolten auch geren ein newe fatzon dar zuᵒ haben / die for nye gesehen
wer.

**Sechs Grundformen des Hobel- und Drehwerks (S. 085, Fig. 6):** Vnd das du wissest was die zierd
sey die man mit dem hobel oder drewerck machen kan / so merck das sechserley sunderlicher ding
sind / darauß man solichs erbet. Das erst ist ein blatte fassen / das ander ein holkelen / das dryt
ein auspogne wellen / das viert ein eck / das fünft ein winckel das sechst ist die
:term:`schlangen lini <schlangenlini>` / die man mag ziehen wie man will.

**Die gewundene Seüle aus umhüllten Kugeln (S. 090–091, Fig. 9–10):** Nuᵒn gedenck vnd nym dir
für / es sey ein yeklicher punct / in der gewunden axt der seulen ein centrum einer kugel / vnnd
reyß darauß auf der selben zwerch lini / darauf der punct der axt stett ein cirkelryß / so dick in
dem selbenn ort die gerad seulenn ist vnd thuᵒ das durch all puncten der axt der gewunden seulen.
So findt sich der seulen dicke durch all jr krüme / so dann dise cirkel all gemacht sind / als dann
far mit einer lini aussen an den zirkelryssen herumb / darauß fint sich der seulen bossen.

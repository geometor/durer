Schattenwurf, Durchsichtige Abschneydung & Glasrahmen-Instrument (Fig. 52–63)
=============================================================================

*(Camerarius 1532: Sciagraphia cubi, Perspectivae ratio ac Machinae opticae.)*

**Zweitafel-Schattenwurf des Würfels (S. 167–168, Fig. 52):** Vnd merck sunderlich das dise zwey
liecht ein liecht sein / des gleychen die lini ``.e.h.`` vnd ``.f.g.`` mit dem plano darunder
``.e.f.g.h.`` ein ding wie for gemelt auch der :term:`nider gedruckt <nidergedruckter-grund>` vnd
:term:`aufgezogen <aufgezogner-grund>` wuᵒrffel ist eins / **suma pede grund vnd pede liecht ist als
ein ding / aber zuᵒm gebrauch von leychte wegen gespalten**.

**Die durchsichtige Abschneydung der Sehstrahlen (S. 169–176, Fig. 54–60):** Das :term:`aug
<augpunct>` sicht allein durch gerad linien die ding die for jm sind / vnd mag durch kein krume lini
sehenn ... Nuᵒn merck das zwischen der weyten des augs vnd des das gesehen wirt soll genumen werden
**ein ebne** :term:`durchsichtige abschneydung <durchsichtige-abschneydung>` **aller der streym
linien die auß dem aug fallen auf die ding die es sicht** / diß eben durchsichtig feld mag im
abschneiden nahent zuᵒ dem aug oder ferr darfon / vnd nahent zuᵒ dem ding das es sicht gestelt
werden ... diß ist der recht grund des :term:`abstelens <abstelen>` was zuᵒ der malerey gehört.

**Glasrahmen & Lauten-Fadeninstrument (S. 178–181, Fig. 62–63):** Wilt du durch zeychnen was du for
dir sihest / so rüst for einen geschickten zeug darzuᵒ / nemlich also. Faß ein reyn flach glas in
ein gefierte ram ... vnnd oben an disen stab mach ein klein dünn geschicktes pretlein vnd por ein
loch dardurch / auf das du darauß mit einem aug dest gewisser durch das glas sehen mügest in der
ram / was du dann dardurch sihest das verzeychen mit einem pensel auß einem glaser lot auf das
glas ... **Durch drey feden magst du ein yetlich ding das du mit erreychen kanst in ein gemel
bringen** / auf ein dafel zuᵒuerzeychnen ... Nuᵒn brauch diß also / leg ein lauten oder was dir
sunst gefelt so ferr von der ram als du wilt / vnd das sie vnuerruckt peleyb so lang du jr bedarfst /
vnd laß deinen gesellen die nadel mit dem faden hinauß strecken / auf die nöttigsten puncten der
lautten / vnd so oft er auf einem still helt vnnd den langen faden anstreckt / so schlag alweg die
zwen feden an der ram kreutzweyß gestrackes an den langen faden / vnd kleb sie zuᵒ peden orten mit
einem wachs an die ram ...

*Gedruckt zuᵒ Nüremberg. Im. 1525. Jar.*

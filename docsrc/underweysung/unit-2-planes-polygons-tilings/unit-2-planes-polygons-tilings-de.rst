Ebne Figuren, Eck vs. Winckel & Acht Fierungen (Fig. 1–8)
=========================================================

*Hernach folget das ander büchlein von den ebnen felderen.* *(Camerarius 1532: Liber Secundus — De
planis figuris et earum coaptatione.)*

Nach dem jch hie forren angetzeigt hab / wie man etlich linien ziehen soll / will jch nun wie jch
im anfang gemelt / an die planos oder ebnen komen / vnd etlich auß den selben figuren der vil sind
leren machen / Damit man aber verstee / was ein planus oder ebne figur sey / ist das ein ding das
durch die linien geendert vnd abgesondert wirdt / vnnd noch kein Corpus schleüst ... Nun ist
wißlich durch den :person:`Euclidem <euclid>` / das zwo gerad linien kein ebne schlissen / darumb
machen sie kein figur / dann sie machen kein gentze / zeücht man sie paralel (:term:`barlini
<barlini>`) / so ist ein ofne zü beden seyten / zeücht man sie dann das sie an einem teyl züsamen
laufen / so bleyben sie hynden ofen.

Aber ee das jch die figuren an heb zuᵒmachen / will jch vor ein wenig von den wincklen reden /
Erstlich soll man mercken / das ein winckel vnd ein eck glech linien haben / Aber die vnderschid
des winckels vnd eckes / im werck ist diser / **Wenn du aussen auf die scherpf sichst / so heist es
eyn eck / sichstu aber jnnen in die tyfe / so heist es ein winckel** / das hab jch vnden
aufgeryssen / zum eck außwendig gesetzt ein ``.a.`` vnd in winckel ein ``.b.``

Man soll auch mercken das dreyerley winckel vnd eck sind / ein rechter ein weyter vnd ein enger /
die werden leichtlich also gemacht / Erstlich zu dem rechten winckel / reiß zwuᵒ gerad lini /
ongeferlich creutzweiß vber eynander / vnnd in dem puncktenn da sie an eynander abschneidenn /
setz ein ``.a.`` vnnd nym ein :term:`zirckel <zirckel>` / setz jn mit dem ein fuß in das ``.a.``
vnd mit dem andern reiß durch drey örtter der gestrackten linien / Vnd wo sie abgeschnyden werden /
da setz ``.b.c.d.`` vnd zeüch ``.b.c.`` vnd ``.c.d.`` mit geraden linien zuᵒsamen / so ist
``.b.c.d.`` ein rechter winckelhacken ... Weyter ist zuᵒ mercken so vier linien / die alle ein leng
haben / zuᵒrechtenn wincklen / an einander gesetzt werden / so machen sie ein :term:`rechte fierung
<fierung>` die sey ``.a.``

Sechseck, Sibeneck, Fünffeck (demonstrative & unverruckt), 11- & 13-Eck (Fig. 9–20)
===================================================================================

*(Camerarius 1532: De figuris aequilateris & aequiangulis — Demonstrative ac Mechanice.)*

**Sechseck & Sibeneck (S. 057, Fig. 9–11):** Erstlich mach ein sechs ecket figur / darum das die
der zirkell vnuerruckt selbs gibt ... Nvn will jch durch den vorigen dryangel / vnd auß seiner
beschreibung durch einen gemeinen weg / den man von behendigkeyt wegen / in der arbeyt braucht ein
siben eck machen / ich thüe im also / ich zeüch ein gerade lini auß dem Centrum :g:`a` in den
punckten ``.2.`` so schneidt sich die seytten des dryangels ``.1.3`` in der mitt von einander in
den selben punckten setz ich ein ``.b.`` so geet die leng ``.1.b.`` siben mal herum.

**Fünffeck & Zeheneck nach Ptolemäus / Euklid (S. 058, Fig. 15, inkl. Druckfehlerverzeichnis S. 182):**
Nvn ist von nötten ein fünfeck zümachen / in ein zirckelryß / dem thuᵒe also / Reiß auß einem
Centrum :g:`a` ein zirckelryß / vnd zeüch ein zwerchlini durch das Centrum :g:`a` vnd da sie zuᵒ
beden seyten die zirckellini durch schneidet / da setz :g:`b` :g:`c` Darnach zeüch durch das
Centrum :g:`a` ein aufrechte lini zuᵒ gleychen wincklen / vnd wo sy eben die zirkellini durch
schneydet / do setz ein :g:`d` *[Korrigenda S. 182: teyl .a.c. mit einem punckten .e. in zwey
gleiche teyl; im ersten cirkel soll .d.e. mit einer lini zusamen gezogen werden]* Darnach reiß ein
gerade lini ``.e.d.`` vnd nym ein zirckel / setz jn mit dem ein fuß in den punckten :g:`e` den
andern in das :g:`d` vnd reiß von dann herab auf die zwerch lini ``.b.c.`` wo sie die durchschneidt
da setz ein ``.f.`` vnd reiß ``.f.d.`` gerad zuᵒ samen / dise lenge ``.f.d.`` ist ein seiten eins
fünfteyls / das ecket im zirckel herum dryt / so ist ``.f.a.`` ein seyten eins zehenecks / Darnach
teyl ``.a.c.`` mit einem punckten :g:`e` in zwey gleiche teyl / so du dann auß dem punckten :g:`e`
mit einer aufrechten lini vbersich ferst / biß an die zirckellini / so hast du ein sibenteil des
zirckels :term:`Mechanice <demonstrative>`.

**Fünffeck auß unverrucktem Zirckel (S. 059, Fig. 16):** Aber ein fünfeck auß :term:`vnuerruckten
zirckel <zirckel>` zuᵒ machenn / dem thuᵒe also / Reiß zwen zirckel durch einander / also das eins
ytlichen ründe / durch des andern Centrum gee / vnd die zwey Centra :g:`a` :g:`b` zeüch mit einer
geraden lini zuᵒsamen / das wirdet ein leng einer seyten des fünften eckes / wo aber die
zirckellini an einander durchschneiden / da setz oben ein :g:`c` vnden ein :g:`d` vnd reiß ein
gerade lini ``.c.d.`` Darnach nym den vnuerruckten zirckel vnd setz jn mit dem ein fuß in den
punckten :g:`d` vnd mit dem andern reiß durch die zwen zirckelryß / vnd jre bede Centro :g:`a`
:g:`b` vnd wo die zwen runden riß durch schnytten werden / da setz :g:`e` :g:`f` Aber wo die
aufrecht ``.c.d.`` durch schnytten wirdet / da setz ein :g:`g` Darnach zeüch ein gerade lini
``.e.g.`` gar hynauß byß an die zirckellini / da setz ein :g:`h` darnach zeüch ein andre gerade
lini ``.f.g.`` biß an die zirckellini da setz ein :g:`i` zeüch darnach ``.i.a.`` vnd ``.h.b.``
gerad züsamen / so werden drey seyten des fünfecks / vnd von dann laß zwuᵒ gleich seyten leng vom
``.i.h.`` oben (:g:`k`) zuᵒsam reichen / so wirdet ein fünfeck.

.. picture:: ../../_static/figures/book2_durer_vs_euclid_pentagon.svg
   :caption: Zweytes Buch, Fig. 16 (S. 059): Dürers Fünffeck *auß unverrucktem Zirckel* (:g:`a`, :g:`b`, :g:`h`, :g:`k`, :g:`i`) im Vergleich zum Euklidischen $\mathbb{Q}(\phi)$-Fünffeck (:g:`H_phi`, :g:`K_phi`, :g:`I_phi` über :g:`phi`).

**Neuneck durch drey Fischblosen, Eylffeck & Dreytzeheneck (S. 060–061, Fig. 18–19):** Ein neün
eck ist durch ein dryangel zuᵒ finden / also / Reiß auß einem Centrum ``.a.`` ein grosse
zirckellini / darein reiß mit vnuerrucktem zirckel / drey :term:`fischs blosen <fischblosen>` ...
So jch bald ein eylf eck in ein zirckel reyssen will / nym jch ein vierteyl von des zirckels
diameter vnd erleng jn ein acht teyl auß jm selbs / vnd far mit diser leng herumb im zirckel das
tryt beileuᵒftig ein / **also das es sich Mechanice / aber nit demonstratiue findet** / Weyter so
jch behend ein .13. eck soll machen / so reiß jch auß einem Centrum ``.a.`` ein zirckellini Darnach
reiß jch ein halbenn diameter ``.a.b.`` vnd schneid den mit einem punckten ``.d.`` in der mit von
einander vnd brauch die leng ``.c.d.`` zü .13. malen im zirckel herum / **ist aber auch mechanice
vnd nit demonstratiue**.

Kreispackungen, Maßwerk & Fünffecks-Estriche (Fig. 21–27)
=========================================================

*(Camerarius 1532: Pavimenta, stellae & quinque rosis pentagonorum.)*

Zuᵒm andern / setzt man die cirkellini rautens weyß an einander / so bleyben albeg zwischen dreyen
cirkellinien hole auß geschnitne drieckette felder ... Vnd wo man der cirkel solicher mas vill an
einander setzt / **so rüren alweg .6. den sybetten an**.

**Zusammensetzung der Fünffecke (S. 066, Fig. 24):** Zuᵒ einem muster setz züm ersten / drey fünf
eck mit jren seytenn / auf ein zwerch lini / also das sie mit jren ecken an einander an rüren /
Darnach setz vnden hergegen / aber drey fünfeck mit jren seyten an die oberen / die auch mit jren
ecken an einander an rüren / so werden zwischen den fünfecken / ablang rauten firung ... Du magst
auch **fünf rosen van den fünf ecken** zuᵒsamen setzen / die all an einander anrüren / vnd darnach
vmb kert / an einander hencken so oft du wilt / vnd das felt darneben auß füllen war mit du wild ...
Item so man die siben eck mit den seyten nach einander an einander setzt / alß das aussen zwey /
vnnd innen ein eck für schiessen / so gend sie in eim cirkel herumm / schliessen aber nit / des
gleychen thünd auch die fünfeck.

Vergleichung der Ebnen & Quadratura Circuli (Fig. 28–36)
========================================================

*(Camerarius 1532: Aequatio planorum & Quadratura circuli mechanica.)*

Nuᵒn ist von nöten ein wenig züwissen / wie man die figuren gegen einander gleych an der inhaltung
müg machenn / also das man ein dryangel mach / vnnd darauß ein quadrat / das so vill inhalt als der
dryangel ... nym zwo seyten / ein lange vnnd ein kurtze / von der vberlengten firung ``.a.b.c.d``
vnd stoß sie nach der zwerch an einander / vnd bezeychnen jr drey puncten ``.e.f.g.`` darnach setz
mitten auf die lini ein puncten ``.h.`` nym ein zirkel setz jn mit dem ein fueß in das ``.h.`` vnd
mit dem anderen reyß auß dem ``.e.`` rund herumb in das ``.g.`` Darnach zeüch auß dem puncten
``.f.`` ein gerade aufrechte lini / biß an die zirkellini / wo sie die an rürt / da setz ein
``.i.`` so du dann vier lini ein ytliche so lang ``.i.f.`` ist zuᵒ gleychenn wincklen zuᵒsamen
setzt / so wirt ein rechte firung darauß / die so vil innen helt als die lang firung.

**Quadratura Circuli (S. 075, Fig. 34):** Von nöten wer zuᵒwisen *quadratura circuli* / das ist /
die vergleychnus eines cirkels / vnnd eines quadrates / also das eins als vil inhielt als das
ander / **aber soliches ist noch nit von den gelerten demonstrirt / Mechanice** / aber das ist
beyleyfig / also das es im werck nit / oder gar ein kleyns felt / mag dise vergleychnüß also
gemacht werden. Reyß ein fierung vnd teyl den :term:`ortstrich <ortstrich>` in zehen teyl / vnd
reyß darnach ein cirkelriß (:g:`O_q`) des Diameter sol achtteyl haben / wie die quadratur zechne
hat.

Seülen, Vitruvius, Sechs Hobelzierden & Gewundene Kugel-Seüle (Fig. 1–19)¶

Das dryt büchlein / von den Corperlichen dingen. (Camerarius 1532: Liber Tertius — De columnis, pyramide, horologiis ac litterarum figuris.)

So man aber von dem gantzen bauwerck oder seynen teylen reden will / acht jch es sey keynem berümbten baumeister oder werckman verborgen wie künstlich vnd meysterlich der alt Römer Vitruuius in seinen bücheren von der bestendigkeyt / nutzbarkeyt / vnnd zierden der gebeü geschryben hab / der halb jme auch for anderen zuᵒfolgen / vnd sich seiner ler zuᵒbrauchen ist. So jch aber ytzo für nym ein seülen oder zwo leren zuᵒmachen / für die jungen gesellen / sich darynn zuᵒ vben / so bedenck jch der deütschen gemüt / dann gewonlich alle die etwas newes bauwen wöllen / wolten auch geren ein newe fatzon dar zuᵒ haben / die for nye gesehen wer.

Sechs Grundformen des Hobel- und Drehwerks (S. 085, Fig. 6): Vnd das du wissest was die zierd sey die man mit dem hobel oder drewerck machen kan / so merck das sechserley sunderlicher ding sind / darauß man solichs erbet. Das erst ist ein blatte fassen / das ander ein holkelen / das dryt ein auspogne wellen / das viert ein eck / das fünft ein winckel das sechst ist die schlangen lini / die man mag ziehen wie man will.

Die gewundene Seüle aus umhüllten Kugeln (S. 090–091, Fig. 9–10): Nuᵒn gedenck vnd nym dir für / es sey ein yeklicher punct / in der gewunden axt der seulen ein centrum einer kugel / vnnd reyß darauß auf der selben zwerch lini / darauf der punct der axt stett ein cirkelryß / so dick in dem selbenn ort die gerad seulenn ist vnd thuᵒ das durch all puncten der axt der gewunden seulen. So findt sich der seulen dicke durch all jr krüme / so dann dise cirkel all gemacht sind / als dann far mit einer lini aussen an den zirkelryssen herumb / darauß fint sich der seulen bossen.

[Folio N1525 p. 108–114]

Nürnberger Sonnenuhren (49° Polhöhe) & Optische Thurnschrift (Fig. 20–27)¶

(Camerarius 1532: Horologia solaria ad elevationem poli Norimbergensem XLIX graduum & Scriptura in turribus.)

Wo du nuᵒn in einer stat bist vnd wild ein horalogium machen / so such zuᵒ dem ersten durch ein instrument / oder in tafelen darzuᵒ gemacht / wie hoch der polus ob dem erdrich erhaben sey / also zuᵒ Nüremberg ist sein höch neun vnd vierzig grad / so zel von dem .b. vbersich biß zuᵒ end des neun vnd vierzigsten grades do setz ein .d. vnd zeuch .a.d. gerad zuᵒsamen / dise lini .a.d. nent man Lateinisch axem mundi / das ist die axt daran die gantz welt vmb get. Darnach zeuch ein andere aufrechte lini wie du foren gelert bist auß dem puncten .d. auf die lini .a.b. zü rechten winckelen / in den selben puncten setz ein .e. dise lini nent man in Latein muralem / aber Teutsch mauerlini / darauß die aufrechten horalogia an die maueren gemacht werden. Darnach zeuch ein gerade lini auß dem puncten .e. an die lini .a.d. zuᵒ gleychen winckelen … da setz ein .f. dise lini nent man in Latein equinotialem … dann was am polus zuᵒ get das get am equinoctial ab / so wirdt in allen vierteylen neun vnnd vierzig grad beleyben / das ist die höhe des polus zuᵒ Nüremberg / vnnd die eyn vnnd vierzig vbrigen grad biß zuᵒ dem zenit ist die weyten von dem equinoctial biß zuᵒ vnserem orizon.

Schrift an hohen Thürnen (S. 114): Es begibt sich oft das man schrift an die seulen / thürn / oder an hohen mauren macht / darumb welicher an ein thuren schreyben will das man die oberst zeyl der bustaben als wol gesech zuᵒ lesen als die vnderst / der mach sie oben gröser dann vnden / durch ein solichen weg / stell dein gesicht so weyt von dem thurn / vnd in der höch wie du wild / diß sey ein punct .c. vnd nym für dich den weg des dryangels .a.b.c. der .16. figur des lini büchleins / vnd las das .a.b. sein die thuᵒren höhe oder want darauf du schreyben wild. Nuᵒn teyl in das cirkeldrum .b.e. mit puncten gleych weyten der zeylen darein du schreyben wild / vnnd als dann far auß des gesichtz puncten .c. mit geraden linien durch all puncten des cirkeldrums .b.e. biß an die aufrecht thuren höhe oder want .a.b.

[Folio N1525 p. 115–141]

Das Lateinisch ABC (Antiqua) & Die Alte Textur (S. 115–141)¶

(Camerarius 1532: De recta ratione formandarum litterarum Latinarum ac Germanicarum.)

Zuᵒ dem ersten vnd Lateinischen bustaben mach zuᵒ einem yetlichen ein rechte fierung darein er verfast werd aber so du den bustaben darein zeuchst so mach sein grösseren zug breyt ein zehenteyl von der fierung / seyten leng / vnd den dünneren zug mach eyns driteyls breyt von dem breyten / das merck durch all bustaben durch das gantz .abc.

Versal A (S. 115): Erstlich mach das .a. also / bezeychen die eck seiner fierung mit a b c d das thuᵒ zuᵒ allen bustaben / vnd zerteyl dise fierung mit zweyen kreütz linien die aufrecht e f die zwerch g h Darnach setz vnden in der fierung bey .c.d. zwen puntten i k eyn zehen teyl hinein / vnd zeuch den dünnen strich des bustaben von dem i vbersich an die fierung von dann zeüch den breyten strich wider herab / also das jre beder breyten aussen die zwen puncten i k an rüren / so beleybt mitten ein dryangel (V) / aber der punct e kumpt oben mitten in den bustaben. Darnach zeüch das .a. vnder dem zwerch strich .g.h. zuᵒsamen / den strich mach eynes dritteyls breyt von der grösseren breyten. Darnach laß an dem breyten strich oben ein rund cirkeldrum hindersich vber die fierung auß streychen / vnd nym den bustaben oben mit einer schlangenlini ab / also das die hölen gegen dem dünnen strich ste / vnd schweyf des bustaben strich vnden auf beden seyten auß / also das sie der fierung eck c d rüren / das thuᵒ mit einem cirkeldrum (SL, SR) des halben Diameter eyn siben teyl von der fierung seyten hab / aber innen hinein laß den auß drit von der grösseren breyten des strichs zwey driteyl weyt fürdretten / das nym zuᵒ bedem teyl mit einem cirkeldrum auß des Diameter des breyten strichs breyt sey.

Versalien O & Q (S. 124–125): Das .o. mach in sein fierung also / reyß in seiner fierung ein Diameter c–b vnd teyl den mit einem puncten i in der mitt von einander / vnd setz des pustaben preiten zugs grössen mit zweyen puncten f g mitten auf den Diameter zuᵒ beyden seyten neben das i die laß zwen centrum sein / vnd reiß auß yetlichem ein cirkellini die zwo seyten der fierung anrüren / vnd wo dann die zwo cirkellini durcheinander lauffen (P1, P2) / da hin zeuch von der hand die duᵒnner preyten des pustaben zug in rechter form … Das .q. mach in sein fierung zuᵒ gleycher weyß wie das .o. foren gemacht ist … nym mit einem cirkel die leng .c.d. vnnd reyß den schwantz von dem runden ryß herauß / die erst lini durch den puncten d so lang da ist .c.d. vnnd das sich der schwantz vbersich krüm biß wider zuᵒ der höhe .c.d. vnd merck den puncten mit einem h.

Die Alte Textur: i, n, m (S. 136): Vnd wiewol man das alpfabet am .a. anhebt zuᵒschreyben / so will jch doch auß vrsach hie zuᵒm ersten das .i. für mich nemen zuᵒmachen darumb das schier alle pustaben darauß gemacht mögen werden / doch muß man jm etwan zuᵒ geben oder nemen. Erstlich das .i. mach auß rechten fierungen / der setz drey aufrecht auf einander / vnd teyl der obersten fierung öberste seyten vnd der vndersten vnderste mit zweyen puncten yetliche in drey gleyche felt. Darnach setz ein gleych mesige fierung vber ort / den Diameter aufrecht mit dem eck in den fordersten puncten der fierung seyten … Item das .n. mach auß zweyen zügen des pustaben .i. also das jr öberste vnd vnderste eck an einander rüren / so wirt das felt schlemer zwischen den zügen dann ein zug des pustaben preyt ist … Item das .m. mach von dreyen zügen wie das .n. von zweyen gemacht worden ist.

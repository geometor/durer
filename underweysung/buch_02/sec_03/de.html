Kreispackungen, Maßwerk & Fünffecks-Estriche (Fig. 21–27)¶

(Camerarius 1532: Pavimenta, stellae & quinque rosis pentagonorum.)

Zuᵒm andern / setzt man die cirkellini rautens weyß an einander / so bleyben albeg zwischen dreyen cirkellinien hole auß geschnitne drieckette felder … Vnd wo man der cirkel solicher mas vill an einander setzt / so rüren alweg .6. den sybetten an.

Zusammensetzung der Fünffecke (S. 066, Fig. 24): Zuᵒ einem muster setz züm ersten / drey fünf eck mit jren seytenn / auf ein zwerch lini / also das sie mit jren ecken an einander an rüren / Darnach setz vnden hergegen / aber drey fünfeck mit jren seyten an die oberen / die auch mit jren ecken an einander an rüren / so werden zwischen den fünfecken / ablang rauten firung … Du magst auch fünf rosen van den fünf ecken zuᵒsamen setzen / die all an einander anrüren / vnd darnach vmb kert / an einander hencken so oft du wilt / vnd das felt darneben auß füllen war mit du wild … Item so man die siben eck mit den seyten nach einander an einander setzt / alß das aussen zwey / vnnd innen ein eck für schiessen / so gend sie in eim cirkel herumm / schliessen aber nit / des gleychen thünd auch die fünfeck.
